# OmniCodeVault

OmniCodeVault collects small practice projects and examples across multiple languages.

## Repository Layout

- `Java/` - Java programs, data structure examples, and OOP exercises.
- `C/` - C programs and algorithm practice files.
- `Python/` - notebooks for Python assignments and practice.
- `TypeScript/` - TypeScript examples.
- `Web/` - HTML, CSS, and JavaScript for web practice.

The repository now uses consistent language folder names so related examples are easier to find and maintain.
